# Invoice Builder App

## Introduction
   This invoice builder app lets you generate invoices for your customers and export them as pdf's.
   This app is built using react and vite. You can add the customer's info and the items they purchased.
   After adding all the items they purchased you can generate a pdf and store it on your pc or send it as email.

## Tools

   It is Primarily built using react and vite. For generating pdf's reactpdf/renderer is being used.
